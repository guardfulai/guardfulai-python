# Guardful AI Python SDK

This repository independently owns the `guardfulai` Python distribution.
Read README.md and CONTRIBUTING.md before changing code. Preserve public imports,
signatures, wire behavior, strict decisions, idempotency and content-free errors.
Use `make setup` for explicit setup and `make check package-check` for validation.
Tests use synthetic data and mocked HTTP; never call a live service for validation.
Keep all source, tests, examples and history suitable for public sharing. Do not
include credentials, personal paths, internal systems or private evidence.
Publishing, release tags and account changes require explicit maintainer authority.
See docs/releasing.md. Keep release artifacts immutable and verify registry hashes.
